# Задание 4

**Условие:** Используя цикл, создать список, содержащий квадраты всех целых чисел от 1 до 10, и вывести его на экран.

**Решение:** `hw1_4.py` / `hw1_4.ipynb`

## Оценка сложности

Пусть `n` - длинна списка.

- **По времени:**  
O(n) - для произвольного `n` сложность линейная.  

  >_Количество итераций_: Цикл `for` будет выполняться `n` раз.  
  _Операции внутри цикла_: На каждой итерации происходят три действия:   
    &nbsp;-генерация числа в `range()`: 𝑂(1),  
    &nbsp;-операция умножения `number * number`: 𝑂(1)  
    &nbsp;-добавление элемента в список через `.append()`: усредненое 𝑂(1).  
  
  >_Итоговый расчет_: 𝑛×(𝑂(1) + 𝑂(1) + 𝑂(1))=𝑛×𝑂(1)=𝑂(𝑛). 
  
  O(1) - при исходных условиях задания, где `n` не является изменяемым входным параметром программы, и значения списка не выходят за пределы Small Integer Cache (пул чисел от -5 до 256).

- **По памяти:**  
O(n) - для произвольного `n` сложность линейная.

  >_Память под список `squares` из `n` элементов_: 𝑂(𝑛).  
  &nbsp;В ходе выполнения алгоритма в него будет добавлено `n` элементов.  
  >_Память под переменные_: 𝑂(1).   
  &nbsp;Переменная number и итератор `range()` занимают фиксированное количество памяти независимо от размера `n`. Итератор `range()` не создает весь массив чисел в памяти заранее.  
  
  >_Итоговый расчет_:  𝑂(1) + 𝑂(𝑛) = 𝑂(𝑛).  

  O(1)  - при исходных условиях задания, где `n` не является изменяемым входным параметром программы.
